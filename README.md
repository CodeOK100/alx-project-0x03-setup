# 🚀 Splash App  
*A Next.js + TypeScript Project*  

## 📖 Overview  
**Splash App** is a modern **Next.js application** that demonstrates best practices in web development. It showcases shared layouts, reusable components, routing strategies, and responsive design.  

The project serves as a **foundation for scalable applications**, making it easy to extend with AI-powered features while keeping the UI clean, professional, and maintainable.  

---

## 🎯 Key Concepts  
- **Layout Components** → Shared `Header`, `Footer`, and `Layout` for DRY (Don’t Repeat Yourself) principles.  
- **Component Architecture** → Modular, reusable components (e.g., custom `Button`).  
- **Routing** → Both declarative (via `<Link>`) and imperative (via `useRouter`) navigation.  
- **Styling** → Tailwind CSS with extended configuration for modern, utility-first design.  
- **TypeScript** → Strong typing with interfaces, ensuring type safety and maintainability.  
- **Error Handling** → Custom 404 pages for improved user experience.  
- **Responsive Design** → Optimized layouts for mobile, tablet, and desktop.  

---

## 🛠️ Tools & Libraries  
- **[Next.js](https://nextjs.org/)** → React framework with built-in routing and SSR (Server-Side Rendering).  
- **[Tailwind CSS](https://tailwindcss.com/)** → Utility-first CSS framework for rapid UI development.  
- **[TypeScript](https://www.typescriptlang.org/)** → Typed superset of JavaScript for scalability and safety.  
- **[React Icons](https://react-icons.github.io/react-icons/)** → Flexible icon library for React projects.  
- **[Google Fonts](https://fonts.google.com/)** → Web font service for consistent, branded typography.
